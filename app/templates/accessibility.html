{{ _('Accessibility statement') }}

{{ _('Last reviewed: July 2026') }}

{{ _('Public participation only works if everyone can take part. Society Speaks is designed so that residents can read, vote and contribute regardless of device, connection, language or assistive technology.') }}

{{ _('Our standard') }}

{{ _('We work to the Web Content Accessibility Guidelines (WCAG) 2.2 level AA as our target standard across the platform, and we treat accessibility issues as bugs, not feature requests.') }}

{{ _('What we have built in') }}

  • {{ _('Keyboard navigation throughout, including a skip-to-content link, visible focus states and keyboard-operable menus and forms') }}
  • {{ _('Semantic HTML with labelled landmarks, headings and ARIA attributes for screen readers') }}
  • {{ _('Colour contrast that meets AA on text and interactive elements, and information never conveyed by colour alone') }}
  • {{ _('A responsive layout that works on small screens and low-cost devices — voting takes one tap') }}
  • {{ _('No account required to participate, which removes the biggest barrier of all') }}
  • {{ _('The interface is available in 11 languages') }}

{{ _('Known limitations') }}

  • {{ _('Some data visualisations (for example opinion cluster charts) are inherently visual; we provide the underlying figures in text and tables wherever they appear') }}
  • {{ _('A small number of older discussions use an embedded third-party tool (Pol.is) whose accessibility we do not control') }}
  • {{ _('Some older pages have not yet been re-audited against WCAG 2.2 and may contain issues; we fix these as they are found') }}
